# Fernando Gali

**Analista de Dados** | SQL · Python · Power BI 

Os dados guardam respostas. Eu faço as perguntas.

Sou Engenheiro de Produção e passei mais de 6 anos do lado de quem usa os dados para decidir: projetos de melhoria contínua, planejamento da produção e gestão por indicadores em plantas de esmagamento de soja e biodiesel, como Key User SAP (PP, MM e CO).

Hoje transformo dados de operação em decisões: rendimento, consumo de utilidades, paradas, estoques e previsão de falta de matéria-prima.
